FxLink Privacy Policy

Last updated: November 23, 2026

Overview

FxLink is a browser extension that converts copied X/Twitter post URLs into FxTwitter URLs.

Data Processing

FxLink processes supported post URLs locally in the browser when they are copied. Copied URLs are not transmitted to the developer or external servers by the extension.

Local Storage

FxLink stores only the automatic conversion preference using chrome.storage.local. This preference remains on the user's device.

Data Collection and Sharing

FxLink does not collect personal information, track browsing activity, use analytics, sell data, or share user information with third parties.

Third-Party Services

FxLink generates links to fxtwitter.com. Opening these links is subject to the destination service's own privacy practices.

User Control

Users can disable automatic conversion from the extension popup or uninstall the extension to remove its locally stored preferences.

Contact

For questions about privacy, visit FxLink GitHub Issues .
